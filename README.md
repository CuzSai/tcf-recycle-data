# TCF Information
To edit information:
- Install Node.js from https://nodejs.org
- run `node sync.js` in root folder
- Edit any json file in Root folder for it to be synced to min and array

## Updating from the Re:Cycle Hub
See HUB-EXPORT.md: export the live game tables from hub.liightning.dev, then `node hub-import.js <export>` and `node sync.js`.
